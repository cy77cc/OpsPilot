# Cluster Policy Release And Rollback Runbook

## 1. 前置条件

- 集群已纳管且状态正常（`active`）。
- 目标策略已在策略中心生成发布单（`release_id` 可见）。
- 目标 CNI 能力确认完成：以 `Cilium` 为主，兼容 `Calico`、`Flannel`。
- 若为 `Flannel`，需确认网络策略执行已开启（`netpol.enabled=true`）。
- 发布操作者具备 RBAC 权限；高风险操作需审批票据。
- 操作中心与审计链路可用（可按 `resource=policy_release` 检索）。

## 2. 发布流程

1. 在策略中心创建发布单，记录 `release_id`、候选版本与稳定版本。
2. 执行仿真，确认无阻断项：
   - 若出现 `SIMULATION_BLOCKING_CONFLICT` 或关键命名空间阻断，禁止继续发布。
3. 在策略中心执行发布：
   - 若返回 `approval_required`，先完成审批，再携带审批 token 重试。
   - 若返回 `completed`，进入“发布已提交”状态。
4. 在操作中心按 `resource=policy_release` + `release_id` 查询轨迹，确认审计落库。
5. 验证策略效果：
   - 业务连通性探测通过。
   - 关键指标有数据：命中/拒绝、发布耗时、仿真耗时、翻译错误。

## 3. 回滚流程

1. 从发布记录读取可回滚版本（优先 `rollback_target_version`，其次 `previous_stable_version`）。
2. 在策略中心触发回滚操作。
3. 若回滚需审批，按审批流程完成后再次提交。
4. 在操作中心确认回滚审计记录存在且状态完成。
5. 复核业务恢复情况与关键链路连通性。

## 4. 故障排查

### 4.1 仿真阻断

- 现象：提示“仿真存在阻断项，禁止发布”。
- 排查：
  - 检查阻断详情是否涉及关键命名空间或策略冲突。
  - 调整策略选择器与规则后重新仿真。

### 4.2 CNI 翻译失败

- 现象：适配器返回语义缺口错误。
- 排查：
  - `Cilium`：避免使用不支持字段（例如不兼容的高级字段）。
  - `Calico`：检查选择器表达式与不支持算子。
  - `Flannel`：仅使用标准 K8s NetworkPolicy L3/L4 子集。
- 指标：查看 `cni_adapter_translation_errors_total`。

### 4.3 审批无法通过

- 现象：持续 `approval_required` 或 token 失效。
- 排查：
  - 确认审批票据有效期与动作范围（cluster/namespace/release/action）一致。
  - 过期时重新申请审批并使用最新票据。

### 4.4 发布后业务异常

- 先执行回滚至稳定版本。
- 检查策略变更影响面与新拒绝流量。
- 对照操作中心审计事件确认执行顺序与版本一致性。

## 5. 升级降级策略

### 5.1 版本升级策略

- 小步快跑：每次只推进一个候选版本。
- 每次升级必须经过“仿真通过 + 审批（若需）+ 审计可追踪”。
- Gateway API 资源变更优先走兼容路径，Ingress 仅保留过渡支持。

### 5.2 快速降级策略

- 发布后出现业务回归时，优先执行策略回滚，不等待下一次发布窗口。
- 降级后冻结同类策略变更，先完成根因分析与补丁验证。

### 5.3 发布控制门槛

- 必须满足：
  - 策略仿真无阻断项。
  - 审批状态满足策略要求。
  - 操作中心能按 `release_id` 查询完整轨迹。
- 未满足任一门槛，禁止进入生产发布。
